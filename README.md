# 🍳 Saborê > **Seu caderno de receitas, do seu jeito.**

O **Saborê** é um aplicativo mobile desenvolvido para organizar receitas de forma simples, bonita e prática.
O usuário pode cadastrar suas próprias receitas, visualizar os ingredientes e o modo de preparo, organizar por
categorias, favoritar receitas e acompanhar quais receitas deseja fazer ou já preparou.

## ✨ Sobre o projeto

A ideia do Saborê surgiu para transformar o tradicional caderno de receitas em uma experiência digital e personalizada.

O aplicativo permite que o usuário tenha suas receitas organizadas em um só lugar, facilitando a busca e o acompanhamento das receitas que deseja experimentar.

## 🎯 Objetivo

Criar uma aplicação mobile funcional que permita:

* Cadastrar receitas;
* Visualizar receitas cadastradas;
* Editar receitas;
* Excluir receitas;
* Favoritar receitas;
* Organizar receitas por categorias;
* Registrar os ingredientes;
* Registrar o modo de preparo;
* Definir o status da receita;
* Manter os dados salvos mesmo após fechar o aplicativo.

## 📱 Funcionalidades

### 🏠 Início

Tela principal com acesso rápido às principais áreas do aplicativo:

* Minhas receitas;
* Favoritas;
* Quero fazer;
* Já fiz.

### 📖 Minhas receitas

Exibe todas as receitas cadastradas pelo usuário.

Cada receita apresenta informações como:

* Nome;
* Categoria;
* Ingredientes;
* Modo de preparo;
* Status;
* Favorito.

### ❤️ Favoritas

Área dedicada às receitas marcadas como favoritas, permitindo encontrá-las rapidamente.

### ✨ Quero fazer

Mostra as receitas que o usuário ainda deseja preparar.

### ✅ Já fiz

Reúne as receitas que o usuário já preparou.

# ➕ Nova receita

Permite cadastrar uma nova receita através de um formulário.

O usuário poderá informar:

* Nome da receita;
* Categoria;
* Ingredientes;
* Modo de preparo;
* Status;
* Se a receita é favorita.

### 🏷️ Categorias

As receitas podem ser organizadas em categorias simples, como:

* 🍰 Sobremesas;
* 🥘 Salgados;
* 🥤 Bebidas;
* 🍽️ Outros.

## 🔄 CRUD

O Saborê utiliza as operações básicas de gerenciamento de dados:

| Operação   | Função                          |
| ---------- | ------------------------------- |
| **Create** | Cadastrar uma nova receita      |
| **Read**   | Visualizar receitas             |
| **Update** | Editar ou atualizar uma receita |
| **Delete** | Excluir uma receita             |

## 💾 Persistência de dados

Os dados das receitas são armazenados localmente no dispositivo para que não sejam perdidos quando o aplicativo for fechado.

Para este projeto, a persistência pode ser realizada utilizando **AsyncStorage**, por se tratar de uma aplicação com dados relativamente simples e de pequeno volume.

## 🎨 Interface

O Saborê possui uma proposta visual:

* Minimalista;
* Moderna;
* Intuitiva;
* Inspirada em culinária;
* Com tons claros e terrosos;
* Cards com cantos arredondados;
* Ícones simples;
* Navegação inferior para facilitar o acesso às principais funções.

A identidade visual busca transmitir uma sensação de **aconchego, cozinha e receitas caseiras**.
